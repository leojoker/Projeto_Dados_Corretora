# 📘 Glossário de Ciência de Dados

Este glossário reúne os principais termos utilizados no desenvolvimento de projetos de ciência de dados com foco em negócios, finanças e futebol.

---

## 🔁 Pipeline
Uma sequência automatizada de etapas (como ETL, modelagem, validação, deploy) que transforma dados brutos em produtos de dados prontos para análise ou aplicação.

---

## 🧪 EDA (Exploratory Data Analysis)
Análise exploratória de dados. Técnicas para entender a estrutura, padrões, anomalias e correlações em um dataset.

---

## ⚙️ ETL (Extract, Transform, Load)
Processo de extrair dados de fontes, transformá-los para limpeza e padronização e carregá-los em destino final (DataFrame, banco, dashboard, etc).

---

## 🏷️ Feature
Variável independente, também chamada de atributo. Pode ajudar a prever ou explicar a variável alvo.

---

## 🎯 Target
Variável dependente que se deseja prever ou classificar. Exemplo: "usuário convertido".

---

## 🧹 Data Cleaning
Etapa de limpeza de dados: remoção de duplicatas, preenchimento de nulos, padronização de formatos.

---

## 🧱 Feature Engineering
Criação de novas variáveis ou transformação de colunas existentes para melhorar a performance dos modelos.

---

## 🔍 Modelagem Preditiva
Aplicação de algoritmos para prever valores ou classificar registros com base em dados históricos.

---

## 🧠 Algoritmos comuns
- Regressão Linear / Logística
- Random Forest
- K-Means
- XGBoost / LightGBM
- SHAP (explicabilidade de modelos)

---

## 🎯 Métricas de Avaliação
| Métrica     | Aplicação                 |
|-------------|----------------------------|
| Accuracy    | Classificação geral        |
| Precision   | Positivos verdadeiros      |
| Recall      | Cobertura dos positivos    |
| F1-Score    | Balanceamento              |
| ROC AUC     | Separação de classes       |
| MAE/MSE     | Erros em regressão         |

---

## 📦 Dataset
Conjunto de dados usado para análise/modelo. Costuma ser dividido em:
- Raw (bruto)
- Processed (tratado)
- Final (pronto para uso)
- Full_Simulated (neste caso, dados criados via faker python)

---

## 🧾 Data Dictionary
Dicionário de dados. Documento que descreve variáveis do dataset: nome, tipo, significado e possíveis valores.

---

## 🧪 Train/Test Split
Divisão do dataset para treinar e testar modelos. Ex: 80% treino / 20% teste.

---

## 💻 Deploy
Publicação do modelo ou sistema para ser usado por outras aplicações (ex: via API ou dashboard).

---

## 📊 Dashboard
Visualização interativa dos KPIs e análises em Power BI, Tableau, Streamlit ou Dash.

---

## 🕵️‍♂️ Anomalias (Outliers)
Valores fora do padrão que podem indicar erro, fraude ou evento raro.

---

## 📉 Churn
Indicador de abandono do serviço por parte de usuários ou clientes.
