# 🤝 Como contribuir

Este projeto foi criado com o objetivo de simular um pipeline completo de ETL, análise e visualização de dados para uma corretora internacional.

## Como colaborar:

1. Faça um fork deste repositório
2. Crie uma nova branch para suas alterações: `git checkout -b minha-contribuicao`
3. Realize os commits de forma clara e incremental
4. Envie um pull request explicando sua proposta de melhoria ou correção

## Sugestões de contribuição:

- Melhorias na análise exploratória
- Novas visualizações no Power BI ou Streamlit
- Integrações com APIs externas ou bancos de dados
- Documentação ou traduções

Toda contribuição é bem-vinda. Obrigado por colaborar!
